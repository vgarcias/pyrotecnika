# Atajos de teclado de fábrica

Son los de Adobe Fireworks CS6 para las acciones que existen en Pyrotecnika. Se cambian en Editar › Preferencias… › Atajos. En macOS, Ctrl es ⌘ y Alt es ⌥.

Este archivo se genera desde el catálogo de comandos (`crates/pyro-ui/src/commands/catalog.rs`): `PYRO_WRITE_ATAJOS=1 cargo test -p pyro-ui tabla_de_atajos`.
